## 原库的核心能力

- **重新布光**：窗光、棚拍、夕阳逆光、低调光和双色霓虹等，要求人物与环境共享一致的光源关系。
- **自然肤质**：分别处理连续肤色、局部反光和尺度／焦点允许的微纹理，避免粗毛孔、颗粒或加深皱纹。
- **曝光与颜色**：分别组织高光、中间调、阴影、黑位、光源颜色和调色风格。
- **成像响应模拟**：用影调、高光过渡和微对比表达数码、胶片、CCD、手机等类别，不声称精确还原厂商色彩科学。
- **范围控制与验收**：按需求保留五官、姿态、构图、光线或景深；失败时报告并提供重新整理的编辑提示词。

## 技术原理与边界

核心理解：**描述光源与投射效果 → 原图和提示词一起传给图像大模型 → 模型生成编辑结果 → 对照验收**。例如“左上宽大柔光，脸部由亮到暗平缓过渡，墙面保留连续柔影”，是对生成结果的要求。原库没有自行计算光线传播；具体光影、材质与细节由模型根据图像和语言条件生成，因此物理一致性和人物保持都需要检查。

本地扩展研究覆盖婚纱照、家庭老照片、职业头像、旅拍、商品图、室内摄影和整组照片统一。各方向所需保护内容、建议处理流程及验证状态见[照片产品扩展](extensions.md)。这些是本地探索，不是原库新增的现成功能。

原始人像与要求 → Agent 确定修改范围 → 选择 L/E/S/P/T/G/D/A 配方 → 编写简短提示词 → 调用宿主图像模型 → 视觉与文件检查。

原库没有自研模型权重或光照求解器。物理一致性是对模型输出的要求；默认后端属于整图生成式编辑，不提供严格蒙版保护、未编辑像素原样保留或固定画布保证。验收脚本检查记录与证据路径，不能独立证明人物保持或图像质量。详见[研究笔记](notes.md)。

## 运行与检查

需要 Node.js 22 或更新兼容版本，无需安装 npm 依赖。在本项目目录执行：

```powershell
node app/scripts/build.cjs
node app/scripts/check.cjs
```

构建结果为 `app/dist/`。使用本机静态服务器预览，例如已安装 Python 时：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory app/dist
```

预览地址 `http://127.0.0.1:8765/` 仅对本机有效。根目录执行 `node scripts/build-pages.cjs` 可检查汇总发布产物。[公开展示](https://yydshly.github.io/0911_codex_project/005-xxg-portrait-rebuild-light/) 已于 2026-09-10 部署并验证。
