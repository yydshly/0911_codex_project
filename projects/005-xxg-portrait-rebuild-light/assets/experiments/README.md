# 本地图像编辑实验

这些文件来自本次真实的内置 ImageGen 调用，不是从上游示例截取，也没有用本地滤镜伪造效果。输入 `source.png` 本身由 AI 生成，并非真人实拍。

## 实验方法

1. 生成一张中性光照的合成成年人像，固定人物、姿态、服装、窗口、背景和构图作为测试输入。
2. 从同一张输入分别请求柔和窗光、夕阳逆光和双色霓虹；不使用前一次输出作为下一次输入。
3. 编辑提示词采用固定研究版本 V2.1 的配方思路，由本地整理为四至五行指令；实际完整文本逐字保留。
4. 各方案只有一次编辑调用。保留全部返回结果，无候选筛选、后期滤镜、裁切、重绘或尺寸修正。
5. 对比图片记录明显变化、未达标要求和不确定项。它们是研究样本，不能推算身份保持成功率或证明摄影上的物理正确性。

## 文件与证据

- `source.png`：共同输入。
- `window.png`、`golden.png`、`neon.png`：各方案实际输出。
- [runs.json](runs.json)：原图与编辑的完整提示词、日期、源文件校验值、输出校验值、原始尺寸、调用时间和视觉观察。

工具未公开的模型版本、随机种子和计费信息应记录为未知，不从图像风格或其他工具推测。网页显示的提示词直接从实验记录读取，避免配方模板修改后与已有结果错配。

## 解释范围

这是“原始图像 + 摄影提示词 → 图像模型编辑”的实际调用演示。没有安装或自动执行上游完整技能，没有执行其严格局部像素保护流程；不宣称已完成上游端到端复现。输入为 AI 图像，也不能由此保证真人实拍的效果。
