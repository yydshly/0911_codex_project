# 能力与同类对比总览图

本图为原创研究示意图，非软件截图或运行结果。依据本项目固定提交研究和已有同类研究绘制，未使用上游图片或像素素材。资料来源见[研究记录](../notes.md)。

| 文件 | 用途 |
| --- | --- |
| [overview.png](overview.png) | 1920 × 2440，供项目与根 README 展示 |
| [overview.svg](overview.svg) | 同内容矢量图，支持放大与文字检索 |
| [build_overview.py](../build_overview.py) | 图中文字与布局的唯一生成源 |

图中包含定位与核心差异、职责链、能力地图、文件投递与终端唤醒、Multica / MetaGPT / LongHorizon / Pi-OMP / Memmy 对比、适用场景、研究意义、扩展候选及验证边界。工具比较的是研究版本的侧重点，不是效果排名。

生成依赖为 Python、Pillow、Playwright 和本机 Chrome，Windows 使用微软雅黑字体。从仓库根目录运行 `python projects/011-munder-difflin/build_overview.py`；生成后检查整图文字、连线与布局。依赖仅用于配图，不是上游应用依赖。
