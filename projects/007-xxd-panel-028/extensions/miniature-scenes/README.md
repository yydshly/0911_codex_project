# 微缩方向的场景扩展

[返回项目](../../README.md) · [六张实际效果图与提示词](../../runs/20260910-miniature-scenes-04/README.md)

本轮固定 XXD Panel 028 的纸面等距微缩审美，扩展内容输入与场景组织方式。不是增加新的绘画风格，也不是原版 Skill 已内置的多图故事工具。

| 方向 | 这次的实际演示 | 从结果理解边界 |
| --- | --- | --- |
| 人物＋场地 | 婚纱人物照与真实草坪婚礼场地照片共同输入 | 场地线索可辨，但仍补充了花瓣与花饰，非事件复原 |
| 人生故事 | 同一人物参考生成咖啡、海边场景，与本轮婚礼图组成三幕 | 日常衣服、动作和经历属于虚构设定，身份保真未量化 |
| 生活地图 | 咖啡、厨房、海边、婚礼四个主题用道路连接 | 尺度夸张、局部物件补全、分块基座；非真实地图 |
| 局部定制 | 以已生成婚礼微缩图为输入，只请求改变花艺颜色 | 淡蓝花艺修改可见，捧花和总体构图目视基本保留；非像素锁定 |
| 空间纪念 | 从真实四人厨房照片生成切面微缩场景 | 主要构件与人物互动可辨；单视图缺少测量与背面信息 |

六个任务配置见 [jobs.json](jobs.json)。每份实际提示词包含完整未改写的上游审美正文、原库纯设计／画布／无文字交付块，然后追加本地参考图角色和场景要求。多图输入、虚构情节、四主题地图以及局部编辑范围均由本地场景块定义，未修改 vendor 原库文件。

模型生成实际图片；本地脚本只准备请求、保存图片与证据，网页负责展示和前后切换。没有用程序画图来代替生图。所有六张 PNG 均为实际 1536×1024、未经后处理；每图一轮生成。

本轮没有制作视频或可旋转三维模型。当前工具清单没有可调用的视频生成能力，真实三维需另接建模／重建工具；静态效果图不代表这些能力已经实现。

在子项目运行 `node app/scripts/build.cjs`、`node app/scripts/check.cjs`。页面随现有站点产物构建为 `miniatures.html`，保留研究索引 009；本轮证据不应覆盖，新实验需另建 run。
