# 风格与交付扩展实验

[返回研究项目](../../README.md) · [实际运行、图片与提示词](../../runs/20260910-style-extensions-03/README.md)

本地扩展的核心是把“审美正文”和“内容保留要求”作为独立配置，再复用原库的交付块。没有修改 vendor/ 中的原库快照，也没有声称原库本来就支持摄影、水彩或跨来源风格套用。

## 扩展的组成

| 层 | 原库已有 | 本地这次新增 |
| --- | --- | --- |
| 风格 | 固定纸面等距微缩风格 | [独立摄影、水彩配置](profiles.json) |
| 内容约束 | 原始风格正文中的人物与场景约束 | 保留原构图、允许重新构图两个配置，均不保证人脸身份保真 |
| 交付 | common preamble、design-only、text-none 等块 | 实际复用这些原始块；没有另写模式规则 |
| 参考图 | 原库连贯壁纸使用来源与定调图 | 跨来源风格参考：婚礼水彩仅提供画法，家庭照片提供人物与场景 |
| 验收 | Agent 查看输出和交付限制 | 六次调用的提示词、输入、输出、哈希、尺寸和人工观察 |
| 成品 | 原库提供条件式拼版辅助 | HTML 海报、相册对页、卡片，准确文字输入与原片字节保留 |

五个任务配置见 [jobs.json](jobs.json)。四张婚纱实验使用同一原始照片，目标 1024×1536；家庭系列图使用另一张原照片和婚礼水彩参考，目标 1536×1024。除了微缩基准，其他都是本地扩展执行，不冒充原始 Skill 的审美输出。

## 如何理解效果

- 风格库：摄影仍有现实材质；水彩改为平面绘画；微缩改变空间与材质表达。
- 保留重点：同一水彩画法下，保留版仍显示墙面，自由版将其化为纸面和花叶。两者都存在细节偏差。
- 系列：两张作品的笔触与纸纹接近，但只验证一次跨来源参考，未做无参考对照。
- 用途：同一实际水彩图可以进入三种网页版式；切换不调用生图，也不改图片字节。
- 可靠交付：原片与网页文字能准确保留；模型生成的人脸、手部和场景事实仍需检查。

## 执行与维护

准备脚本读取配置和原库块，产出完整实际提示词；宿主 Agent 使用内置 imagegen 生成，再原样复制 PNG、写入目视检查。本页面展示已执行结果，不含上传或实时生图服务。

本轮记录不允许静默覆盖。以后新增实验应创建新的 run 与任务配置；不能重复运行准备命令来覆盖本轮证据。

在子项目目录执行 `node app/scripts/build.cjs` 与 `node app/scripts/check.cjs`。后者包含扩展记录、原片保留与资源检查。研究与演示仍属于研究索引 009，不新增原库计数。
