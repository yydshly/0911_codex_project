03 / HOW IT WORKS

固定审美，明确交付，逐张验收。

阅读上游工作流 ↗
  1. 01

    输入照片

    一张图片或图片目录；每个来源保持独立。

  2. 02

    保留风格原文

    完整使用中文原始提示词，规定主体、色彩和材质。

  3. 03

    追加交付要求

    每张成品只传一个模式，加上比例、文字与语言。

  4. 04

    模型生成与检查

    模型完成整张画布，Agent 检查辨识度、文字和尺寸。

哪些由代码负责，哪些依赖模型？

Python 脚本负责接口调用、PNG 保存、尺寸处理、条件式拼版与偏好存储。主体保真、审美与文字准确性依赖模型和验收；没有自带模型权重，也不产出可编辑三维资产。尺寸校准可能缩放或裁切。
