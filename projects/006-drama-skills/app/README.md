# Drama Skills 中文公开展示

本地新增的静态阅读网页，展示原库完整流程图、11 个技能、7 种材料入口，以及一句话点子和小说选段的两种实际案例。可打开原始创作资料并复制提示词。公开页面不提供在线生图或原库创作台后台。

## 构建与验证

Node.js 22 或更新版本；零第三方依赖，无依赖锁文件。在仓库根目录运行：

```text
node projects/006-drama-skills/app/build.cjs
node projects/006-drama-skills/app/check.cjs
```

在 `app/dist` 启动静态 HTTP 服务即可预览。页面所有站内资源使用相对路径，适配 GitHub Pages 子路径。`dist` 由 CI 构建、不提交。

构建从 `content.cjs` 的明确清单读取案例文档，只复制流程图、真实六格图和一张原库创作台截图，不导出运行目录、凭据、整个工作区或模型适配器配置。公共阅读副本将本机绝对输出路径替换为说明；原始执行记录保留在研究目录。

检查覆盖技能和入口数量、案例与文档关联、六镜结构、静态资源、锚点、脚本语法及本地运行地址泄露。浏览器另检查案例切换、资料阅读、关闭、入口切换、技能展开和窄屏布局。

发布使用仓库既有的 [GitHub Pages 统一约定](../../../docs/web-demos.md)。完整制作与失败边界以 [研究说明](../README.md) 和案例原始记录为准。
