# 从一句话点子到首集：《空房签收》

> 一个外卖员每天给同一间空房送餐，直到某天门内传出了自己的声音。

[返回演示合集](../README.md) · [技能与效果逐步对照](技能与效果逐步对照.md) · [完整首集剧本](剧集/EP001/剧本.md) · [可复制图片提示词](提示词使用指南.md) · [执行与检查](演示记录.md)

**这次展示“只有一句话，大模型怎样继续创作”。** 使用原库项目工具建立项目，再按 develop、write、assets、image-prompts、storyboard 等技能完成本地原创材料。题名、人物、谜底方向与分镜均由当前 Agent 补充，不是原库内置内容，也不是脚本自动生成的剧本。

## 先看首集发生了什么

片名《空房签收》，主角许川。规划三集，首集完整创作，后两集只保留可追踪大纲。首集目标 60 秒、一条走廊、一位可见演员。

| 时间 | 实际写出的场景 | 对应效果 |
| :--- | :--- | :--- |
| 0—10 秒 | 许川把餐袋放在 1204 门外：“第七天了，还没人。” | 用日常行动交代重复送餐 |
| 10—20 秒 | 门内用同样声音复述送餐话术，然后说“我已收到” | 声源与身份发生矛盾 |
| 20—30 秒 | 手机在他没有点按时变成“已签收”，餐袋仍在门外 | 从感觉异常变成可见证据 |
| 30—40 秒 | 他问敲几下，再敲两下；门内准确回答 | 说明有响应机制，但不急于宣布身份或技术 |
| 40—50 秒 | 他举手机开始录像：“再说一遍，谁收的？”门内沉默 | 主角主动取证，改变对方行为 |
| 50—60 秒 | 他收回餐袋后退，门内说“许川，明天换个人来” | 带着新证据与明确下一步压力离开 |

时长是规划，不是实测成片时长。首集没有展示屋内；原点子中的空房事实安排在第二集由物业见证揭示。门内音色需后续真实声音验收，静态图片无法证明声线相同。

## 从点子增加了哪些内容

三集安排：**第 1 集“空房替我签收”**发现异常并带走结尾录像；**第 2 集“屋里没有收件人”**由物业见证空置房与发声设备；**第 3 集“这次一起签收”**用共同见证阻止声音继续替代交付事实。这里只完整生成第 1 集，其余两集是发展规划。

| 层次 | 本次新增 | 产物 |
| :--- | :--- | :--- |
| 开发 | 现实悬疑方向、主角追求与代价、三集推进 | [创作简报](项目开发/creative-brief.md)、[故事引擎](项目开发/story-engine.md)、[分集地图](项目开发/episode-map.jsonl) |
| 写作 | 首集动作、逐字对白、屏幕证据与声音位置 | [剧本](剧集/EP001/剧本.md) |
| 视觉 | 人物衣服、走廊地理、房门状态、手机与餐袋连续性 | [视觉设定](剧集/EP001/视觉设定.md) |
| 镜头 | 六镜职责、起终点、时长、声音与冻结画面 | [分镜](剧集/EP001/分镜.md) |
| 提示词 | 人物参考、场景道具参考、六镜起始画面 | [图片提示词](剧集/EP001/图片提示词.md)、[汇集指南](提示词使用指南.md) |

当前聚焦创作与图片，不执行视频、配音、音乐或剪辑；不需要先配置视频账号。
