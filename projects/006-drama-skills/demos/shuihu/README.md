## 六个镜头怎样讲完这段戏

| 时间 | 画面与行动 | 剧情作用 |
| :--- | :--- | :--- |
| 00—10 秒 | 林冲裹着旧被喝冷酒，忽闻远处爆响 | 从片刻安稳转为警觉 |
| 10—20 秒 | 放下酒器和被子，起身从墙缝看见草料场大火 | 让异常声音变成可见危险 |
| 20—30 秒 | 他拿枪准备救火，门外三人推门、低语；他停住 | 保留原著的行动因果 |
| 30—40 秒 | 门外说“逃出来，烧了草料场，也是死罪”；林冲听出旧友声音 | 发现这场灾难是有人设下的死局 |
| 40—50 秒 | 先把枪靠墙，再双手搬走石头，起身重新握枪 | 用实际行动表现不再忍让 |
| 50—60 秒 | 一手持枪，一手开门：“泼贼哪里去！”切黑 | 完成本片段的反抗转折，止于交锋之前 |

对白为本地压缩改写；六镜时长是设计目标，尚未由视频或朗读实测验证。选段来自 100 回本第十回，不是全书或全回改编。

## 这次真正用了库的哪些能力

| 环节 | 本次操作与产物 | 能验证什么 |
| :--- | :--- | :--- |
| 原著接入 | 保存六段原文，运行上游章节索引工具 | 识别为第十回、1 条选段记录、14 行；不声称完整章覆盖 |
| 改编与写作 | 按技能从来源提取因果，写 60 秒单场剧本 | 从避寒、救火意图到反抗的转变是否成立 |
| 视觉资产 | 区分人物、地点、道具及状态 | 棉袍不变，白布衫和毡笠留在供桌，枪与石头不会错误交接 |
| 分镜 | 六镜有来源、时长、目的、起点、动作和终点 | 每个信息和动作由哪一镜承载 |
| 生成规格 | 图片提示词与视频提示词逐项保存 | 将故事翻译成模型能够接收的具体要求 |
| 创作台 | 启动原库本地服务，载入真实文件 | 可以浏览项目、阅读和编辑五文档 |
| 机械检查 | 运行上游五文档检查器 | 引用、素材路径和镜头时长等是否成立；以验证记录为准 |

本次图像请求通过 Codex 内置 imagegen 发起，与上游供应商适配器分开记录；未调用上游付费视频服务。视觉生成结果、失败和审查状态见[演示记录](演示记录.md)。

## 在本机继续查看

当前任务已打开原库创作台。服务只在本机运行；没有部署到公开网站，也没有将临时访问令牌写入本说明。

换机器复现时，先按项目研究笔记取得固定上游，在包含本示例的 `demos` 目录启动：

```text
python <固定上游目录>/skills/short-drama/scripts/dashboard_server.py --workspace <本项目目录>/demos --port 0 --detach
```

打开命令输出的本地地址。查询地址用 `--status`，结束服务用 `--stop`；二者使用同一 `--workspace`。运行状态目录已在本项目忽略规则中排除。
