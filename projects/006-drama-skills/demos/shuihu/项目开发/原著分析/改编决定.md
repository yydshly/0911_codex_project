# 选段分析与改编决定

[原著来源](../../原著来源.md)

| 原著依据 | 戏剧功能 | 本片实现 |
| :--- | :--- | :--- |
| 雪压草厅，火种被雪水浸灭 | 排除林冲自己失火，建立幸存的偶然性 | 在导读说明前因；正片不重复演一遍 |
| 庙内喝冷酒，脱下湿白布衫和毡笠 | 建立仍想安身的状态与衣物事实 | 第 1 镜；湿衣帽保留在供桌上 |
| 听爆响，从壁缝看见草场火起 | 由避寒转为救火 | 第 2 镜，火光首次出现 |
| 三人脚步、推门、廊下私语 | 阻止贸然出门，让主人公获得新信息 | 第 3 镜，石头堵门有实际作用 |
| 即使逃生仍要问死罪 | 摧毁继续忍让的可能 | 第 4 镜对白与林冲反应 |
| 轻移石头，挺枪拽门 | 从被动承受到主动行动 | 第 5—6 镜，停在喝止对方的瞬间 |

## 本集契约

- 演示制作选择：60 秒、6 镜、9:16，写实国风电影分镜；未伪称创作者已逐项审定。
- 人物目标：开始只想挨过风雪；听到阴谋后决定面对门外三人。
- 视点：始终跟随庙内林冲；门外人用脚步、推门与画外声呈现，不增加可识别的反派视觉资产。
- 前因供阅读者理解；成片定位为经典章节片段，不声称独立讲完林冲生平。
- 台词少于一分钟可承载上限，给动作与沉默留时间；10 秒是分镜规划，不是模型或实际表演保证。
- 本次重点验证文件交接、实际图像参考与结构校验，真实视频供应商尚未选择。
