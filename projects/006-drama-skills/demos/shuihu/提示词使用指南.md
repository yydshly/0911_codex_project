## 1. 先看懂故事：一张六格叙事板

关联：short-drama-write 提供剧情，short-drama-assets 提供视觉事实，short-drama-storyboard 提供镜头设计；我们将这些内容汇总为本地展示图，实际出图由宿主 imagegen 执行。不是上游 produce 适配器实跑。

预期效果：同一个林冲经历饮酒、望火、止步、识破、搬石、开门，六格让人一眼读懂情绪和行动变化。第 5 格表现正在搬石的代表性时刻，不是视频的冻结起始画面。

来源：[本次直接生图提示词](生成记录/直接生图提示词.md)。

```text
为《水浒传》林冲风雪山神庙画一张精美的六格电影故事板，横向画布，三列两行，按阅读顺序讲故事，格间细分隔线，仅标数字01—06。写实中国古装电影概念插画，冷蓝灰雪夜与远方橙色火光，沉静、紧张、有电影质感。六格始终是同一个林冲：三十五岁中国男子，长脸短须，黑发束髻，深靛蓝旧棉袍、灰布腰带、黑布靴，不戴帽，无白色外罩。地点是北宋破旧木石山神庙，背墙神像和供桌，正门向内开。01：林冲坐供桌旁，灰被盖腿，举棕色酒葫芦喝冷酒，枪平放纸堆；湿白外衫和毡笠放供桌，石头抵住关闭的门。02：他放下被子酒器，站在墙缝边看远方草料场起火，双手空着。03：他右手取起木杆铁尖长枪，站在仍关闭的门内侧耳听门外的人，堵门石仍在。04：林冲面部近景，听出阴谋，下颌绷紧，眼神由惊转怒，火光映脸。05：枪先靠在侧墙，林冲双手把堵门石移到门内左侧，门仍关闭，双手都在石头上。06：从门外看林冲，左手拉开一扇门，右手持枪，立在门槛内怒喝，衣摆迎风雪，门外三人留在画外。庙内没有火焰和积雪，火在远方；无战斗、血迹、对白气泡、水印、现代物件。六格人物衣着一致，道具不重复不悬浮。这是六个代表性时刻的展示图，不是视频起始帧。
```

## 2. 固定美术方向：人物、场景、道具参考板

关联：short-drama-assets 决定视觉事实，short-drama-image-prompts 将事实写成出图规格。

预期效果：一张分区参考板看清林冲衣着、庙内布局与道具。它不负责讲完整剧情，也不直接替代任意一镜的起始帧。

来源：[图片提示词 / IMG-SHUIHU-REFERENCE](剧集/EP001/图片提示词.md)。

```text
生成一张《水浒传·林冲风雪山神庙》短剧的正式美术参考板，横向1536×1024，三个清晰分区，精细中国电影分镜概念插画，写实人物与手绘电影美术质感，克制、冷峻，不模仿任何影视演员。左侧约40%是一位三十五岁中国男性林冲的正面全身与四分之三近景：高挑结实，长脸，短须，黑发束髻，右颊浅淡刺配痕迹，深靛蓝旧棉袍、灰布腰带、黑布靴。此刻在山神庙内，他没有戴帽，没有穿白色外罩。中间约40%是同一座北宋乡野山神庙的空室内地理设定：单间破旧木石庙，正前方两扇向内开的旧木门，门内右侧墙壁有窄裂缝可以窥见远方草料场；背墙正中金甲山神像、旧木供桌；纸堆在供桌左侧；地面一块能被双手搬动的厚重不规则堵门石。外面风雪夜；庙内本身没有点火，照明是门缝与墙缝的冷月色。右侧20%是道具静物板：一柄朴素木杆铁尖花枪；棕色酒葫芦；旧灰色絮被；湿白布外衫与灰毡笠并放供桌上。冷蓝灰、木褐、低饱和赭金的统一色板。表现清楚衣物和道具归属，无战斗无血迹无现代物品。美术板不是连续剧情，不要把多个林冲画进同一个场景。可以有三处简洁中文栏目文字：人物、山神庙、道具。其他不加文字、编号、水印。
```

## 3. 看懂每镜从哪里开始：六张冻结画面提示词

关联：short-drama-storyboard。此技能拥有每镜的冻结起始画面；下列内容直接摘自[分镜](剧集/EP001/分镜.md)，不另造六份资产提示词。

这些正文可以用于单独试画构图。当前没有真实人物和场景参考图，因此单独生成时的身份一致性仍需检查；本页没有绑定不存在的文件，也没有宣称这六张图已生成。

### SHOT-EP001-001 · 借一口酒挨过风雪

本镜效果：先建立避寒的脆弱安稳，让远方爆响打断它。

```text

```

## 4. 出图后怎样对应检查

| 核对点 | 关联技能 | 本例具体看什么 |
| :--- | :--- | :--- |
| 剧情信息 | short-drama-write、short-drama-storyboard | 是否看得出警觉、识破、反抗的变化 |
| 人物一致 | short-drama-assets | 同一长脸短须、束髻、深靛蓝棉袍；没有突然戴帽或披白衣 |
| 空间与道具 | short-drama-assets、short-drama-storyboard | 庙内无火，堵门石先堵后移；双手搬石时枪靠墙 |
| 时刻正确 | short-drama-storyboard | 起始帧不能提前完成本镜动作；六格展示图则采用代表时刻 |
| 实际偏差 | short-drama-review | 用返回图像指出具体位置和问题，不凭提示词推断成功 |
