# Drama Skills · 场景演示合集

[返回项目](../README.md) · [原库能力流程图](../assets/capability-workflow.png)

同一个原库，展示两种不同的创作入口。案例均为本地材料，原库创作台真实运行；图片生成以各案例回执为准，不冒称已有视频。

| 入口 | 案例 | 核心能力 | 可查看产物 |
| :--- | :--- | :--- | :--- |
| 一句话点子 | [《空房签收》](empty-room/README.md) | develop 补全故事方向、冲突与三集规划，再接首集创作 | 简报、故事引擎、三集地图、首集剧本、视觉设定、六镜与提示词 |
| 已有原著 | [《水浒传·风雪山神庙》](shuihu/README.md) | novel-analyze 守住原著因果，再进行选段改编 | 原文依据、选段索引、改编决定、首集剧本、视觉设定、六镜与提示词 |

在原库本地创作台顶部的项目选择器切换两例。共同工作区为本目录，项目内容独立保存，均归入 Drama Skills 研究索引 008，不新增研究条目。
