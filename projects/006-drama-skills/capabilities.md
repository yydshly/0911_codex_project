## 全部技能入口

固定版本有 11 个技能目录：1 个总入口和 10 个专业技能。下表描述上游已有职责；质量效果取决于输入、宿主模型和生产服务。

| 技能 | 输入与工作 | 主要产出 | 依赖或边界 |
| :--- | :--- | :--- | :--- |
| `short-drama` | 初始化、路由、制作形态、视觉方向、创作台 | 项目配置、方向决定、资料导出 | 总入口可选；创作台不承担媒体生产 |
| `short-drama-novel-analyze` | 原著索引、快评、逐章分析、聚合 | 原著分析、改编价值、分集候选 | 不直接写剧本 |
| `short-drama-develop` | 从点子或长材料建立系列冲突；对多集整稿切片续做 | 创作简报、故事引擎、分集地图 | 不补造不存在的上游 |
| `short-drama-write` | 单集目标、因果节拍、行动、对白和声音 | `剧本.md` | 模型创作，需要审查 |
| `short-drama-assets` | 身份、造型、场景视图、道具状态与声音方向 | `视觉设定.md` | 视觉事实不等于生成图片 |
| `short-drama-image-prompts` | 将已决定的资产或风格写成参考图要求 | `图片提示词.md` | 提示词不是图片文件 |
| `short-drama-storyboard` | 镜头职责、来源、景别、时长、起终状态 | `分镜.md`，含冻结关键帧提示词 | 不直接生成媒体 |
| `short-drama-video-prompts` | 动作、表演、运镜、声音和参考要求 | `视频提示词.md`，可含音乐规格 | 按目标模型能力编写 |
| `short-drama-produce` | 预览、确认、调用外部适配器 | 图片、视频、TTS 或音乐素材及记录 | 需要可用服务、配置与本次任务确认 |
| `short-drama-edit` | 素材可用片段、入出点、镜序、声音、字幕 | `剪辑单.md`、成片 | 需素材及 FFmpeg/FFprobe |
| `short-drama-review` | 事实、连续性、内容与已有媒体检查 | 审查意见、结论与责任归属 | 不在同一工作单元改写来源 |

对应上游同名目录的 `SKILL.md`，可从[固定版本技能目录](https://github.com/zenstory-ai/drama-skills/tree/dc9b0fac15225629856f17ca06640b470c89cfca/skills)逐项核对。

## 一个点子怎样变成制作材料

以下是**本地原创说明案例**，解释各产物的职责，未执行上游技能或生成媒体，不是完整可投产项目。

**输入点子：** 雨夜便利店，顾客落下一串钥匙。店员追到门口，才发现钥匙牌上的地址竟然是自己家。

| 阶段 | 本地示意内容 | 让下游明确什么 |
| :--- | :--- | :--- |
| 剧本 | 顾客离开；店员发现钥匙；追到门口；看清地址后停住 | 事件顺序与观众知情时机 |
| 视觉设定 | 店员穿深绿色围裙；银色钥匙配白色地址牌；室内暖光、门外雨夜 | 人物、道具和环境事实 |
| 图片提示词 | 分别描述店员参考板、便利店空间、钥匙道具板 | 要准备哪些参考图，各自负责什么 |
| 分镜 | 第一镜顾客离店；第二镜发现并拿起钥匙；第三镜追到门口后低头读牌 | 每镜动作与信息由谁承载 |
| 冻结关键帧 | 第三镜起点是刚到门口、手握钥匙，地址尚未展示给观众 | 起始画面不能提前泄露结尾 |
| 视频提示词 | 店员从门外收回视线，低头翻转地址牌，停住；指定时刻展示地址 | 动作起终点和揭示时机 |
| 实际生产 | 绑定真实角色图、场景图、道具图，再预览和确认 | 服务实际读取哪些素材、生成哪些文件 |
| 剪辑与审查 | 衔接可用素材，检查地址可读性、反应与声音 | 成片有没有表达出故事 |

这里不指定精确镜长与模型参数，它们需结合目标时长、表演和生成服务决定。地址是否准确可读，只能在生成结果中验证。

## 如何选择起点

| 当前需求 | 对应上游能力 | 不必先做的事 |
| :--- | :--- | :--- |
| “小说值不值得改？” | 原著分析的抽样快评 | 直接拆完整部小说、生成素材 |
| “只有点子，想变成系列” | 故事开发 → 分集写作 | 先确定全部图片和模型 |
| “剧本已定，帮我拆分镜” | 视觉事实提取 → 分镜 | 重写故事开发文件 |
| “我用自己的工具出图和视频” | 提示词与逐镜挂图计划 | 为获得提示词而安装生成适配器 |
| “已经有素材，想剪一版” | 剪辑 | 补造完整制作历史 |
| “看看哪里有问题” | 指定范围审查 | 自动启动新一轮生产 |

## 常见误解

- **提示词就绪 ≠ 已有媒体。** 文本条目与真实文件职责不同。
- **连续性规范 ≠ 模型保证。** 相同参考和文字约束仍可能发生画面漂移。
- **生成成功 ≠ 成片可用。** 文件返回、时长正确与叙事质量是不同判断。
- **创作台保存 ≠ 启动生产。** 编辑保存内容，外部生成通过独立任务执行。
- **五文档 ≠ 项目仅五个文件。** 分析、配置、审查和后期记录可以独立存在。
