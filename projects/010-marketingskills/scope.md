# Marketing Skills：范围、能力与交付摘要

**这是供 Agent 使用的营销方法库。** 固定研究版本包含 50 个技能，覆盖从产品与用户理解，到内容、搜索、推广、转化、客户关系、留存及效果验证的工作。技能规定任务适用条件、需要的资料、分析步骤、参考框架与产物要求；宿主 Agent 读取这些方法，复用产品背景，并通过可用工具完成工作。

适合独立开发者、创始人、技术营销人员与小团队：在缺少专职营销分工时，为具体任务提供结构化方法和可检查的交付。输入通常包括产品说明、目标受众、真实用户材料、已有页面或内容、业务指标、资源和约束；缺少证据时形成待验证草案。

## 技能覆盖哪些范围

以下八类为本地归纳，合计 50 个技能；名称和数量固定于本次研究提交，不代表上游未来版本。

| 范围 | 数量 | 代表技能 | 主要能力与典型产物 |
| --- | ---: | --- | --- |
| 定位与决策 | 9 | product-marketing、customer-research、offers、pricing | 整理产品和受众背景、分析用户与竞争、设计价值方案、定价与策略；输出背景文档、研究结论和方案 |
| 内容与创作 | 5 | content-strategy、copywriting、copy-editing、image、video | 规划内容、撰写与编辑营销表达，指导图片和视频制作；媒体生成依赖外部模型或工具 |
| 搜索与发现 | 8 | seo-audit、ai-seo、programmatic-seo、schema | 诊断可发现性、组织站点与批量页面、结构化信息；输出审计、页面规划及实现建议 |
| 页面与转化 | 5 | cro、signup、onboarding、paywalls | 分析页面、表单、注册、首次使用和升级流程；输出阻碍分析、改进方案与待验证假设 |
| 传播与推广 | 8 | launch、ads、ad-creative、social | 规划发布、广告与创意、社交、公关、活动及合作；输出推广计划、内容与素材要求 |
| 销售与客户关系 | 6 | prospecting、cold-email、sales-enablement、emails | 发现潜客、组织销售材料与客户沟通、生命周期邮件和运营；输出名单要求、文案与流程 |
| 留存与增长 | 6 | churn-prevention、referrals、marketing-loops | 分析流失、推荐、社区和获客材料，设计有状态的重复行动；输出干预策略与循环定义 |
| 衡量与实验 | 3 | analytics、attribution、ab-testing | 定义事件和指标口径、分析渠道贡献、设计实验；输出跟踪计划、分析与实验方案 |

全部技能的输入、方法、产物、验收与协作见[中文完整手册](catalog.md)。

## 技术原理与边界

任务 → 匹配技能描述 → 读取 SKILL.md → 结合共享产品背景和按需参考资料 → 宿主调用工具 → 检查输出与证据 → 反馈修订。

`.agents/product-marketing.md` 用于跨任务复用定位、受众、品牌语言与事实。64 个工具脚本和 95 份接入指南是独立的源码统计，不能相加当作已连接的平台数量。账号、认证、费用、权限、接口兼容性和定时调度需要单独配置。

技能本身不是训练好的新模型，也不是自带业务数据的营销系统。文档方法不会自动产生真实客户研究、保证增长、验证因果或执行对外投放。实际质量取决于输入证据、宿主判断、工具条件和验收。

## 这里实际展示到了哪一步

- 50 技能中文解读、八类能力地图、六个教学流程和完整工具目录；六个教学流程是预编写说明。
- 当前 Agent 实际应用 product-marketing → offers → copywriting → analytics → marketing-loops，基于当前研究资料生成定位草案、交付方案、页面文案、验证计划与推进规则，保留原文、输入及输出证据。
- 本地新增任务单入口：三条代码理解路线、Markdown 导出、反馈 JSON 导出；新增手动循环执行器，保存去重状态与日志。网页不实时调用模型或分析用户仓库。
- 复用 Graphify 的既有 FastAPI 运行记录；另完成一次固定源码的静态走查。程序检查与源码走查不等于客户需求、用户收益或付费意愿已被验证。
