# 产品入口文案

执行技能：copywriting 2.0.2；输入：产品背景 0.1、02-offer.md、固定运行记录。页面目的：让读者带具体问题生成一份任务卡。没有客户评价、节省时间比例或购买承诺。

## 主版本

标题：**接手一个陌生代码库，先找到阅读与验证的起点。**

副标题：开源落地实验室把中文研究、固定版本的运行证据与验收步骤放在一起。先用 FastAPI 的真实结构提取案例，写下你的问题，形成下一步任务单。

主行动：**生成我的上手任务单**。次行动：**先看真实证据**。

问题段：仓库已经收藏，演示也看过，接下来应该读哪个文件、核验哪条关系？从具体问题出发，把资料变成可执行的阅读与验证步骤。

方法段：写下任务 → 了解案例范围 → 选择阅读路线 → 导出核验清单 → 记录结果和阻碍。

证据段：已有 Graphify 运行记录覆盖 FastAPI 核心包 48 个 Python 文件，得到 747 个节点和 1,971 条关系。其中 237 条标为推断，需要进一步核验。该记录用于展示方法，不能代替对你项目的分析。

FAQ：

- 会自动分析我的仓库吗？当前入口只在浏览器内生成任务单，不下载、上传或运行你的代码。
- 我能直接相信图里的调用关系吗？先区分提取与推断，再回到固定版本源码；静态图不等于运行时轨迹。
- 需要付费或注册吗？当前本地示范无需注册和支付。它用于验证任务入口是否有用。
- 做完后得到什么？一份可编辑 Markdown 任务单，包含问题、证据边界、核验步骤和结果记录位置。任务是否完成需要实际执行后记录。

## 表达理由与备选

主标题强调用户眼前任务，避免承诺已经读懂整个仓库。主行动对应已实现的文件产物，不写“自动完成分析”。证据数字紧邻范围与限制，避免被误解为准确率。
