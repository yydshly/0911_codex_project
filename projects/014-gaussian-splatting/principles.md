# 六条技术路线：怎样从图片得到空间

[返回总览](understanding.md) · [产品对比](comparison.md) · [3DGS 实现细节](implementation.md)

**重建过程与三维表示必须分开讨论。**摄影测量和几何预测主要描述怎样求解；网格、距离场、辐射场和高斯主要描述怎样表示；生成式三维描述信息不足时如何利用先验生成资产。这六类不是互斥的六个盒子。

## 共同起点：为什么多角度照片有用

一张照片把三维世界投影到二维，许多不同形状都可能产生相似图像。换一个拍摄位置，近处与远处的点会产生不同的相对位移，这种视差提供了深度线索。相机只在原地转动而没有足够平移，可能适合全景拼接，却不足以稳定恢复深度。

多视角重建通常要求照片有重叠、内容清晰、被摄物基本静止。视频的价值在于提供连续视角；大量模糊或重复帧不一定比少量清晰、覆盖充分的照片更有效。未拍到的背面与遮挡区域，不能仅靠增加训练次数恢复可靠事实。[COLMAP 教程](https://colmap.github.io/tutorial.html)

## 路线 1：摄影测量与网格重建

**原理：匹配同一个物理点，通过多个观察方向求位置，再恢复表面。**

1. 检测图像特征并匹配：例如在不同照片中寻找鞋面上的同一花纹；SIFT 是经典方法，也可以采用学习式特征和匹配器。
2. 估计相机关系：用几何约束和鲁棒估计剔除错误匹配，求相机姿态。
3. 三角测量：结合不同相机的视线计算空间点，形成稀疏点云。
4. 束调整（BA）：联合优化相机参数和空间点，使点投影回各照片的位置尽可能符合观测。
5. 多视图立体视觉（MVS）：估计更密的深度，并进行一致性检查与融合。
6. 表面重建与纹理：由深度或点云生成网格，把图像颜色映射到表面；不同软件不一定必须先显式导出稠密点云。

典型结果是点云、三角网格和纹理。COLMAP 提供 SfM/MVS；RealityScan、Metashape 将重建组织为面向资产或测绘的完整流程。[COLMAP](https://colmap.github.io/tutorial.html)、[Metashape](https://www.agisoft.com/features/professional-edition/)

优势是几何表面明确，便于编辑和测量；局限是弱纹理、重复纹理、反光、透明和运动会使匹配与深度不稳定。单目多图通常仍有尺度不确定性；实际尺寸需要尺度参考，准确度需要独立检查。网格也不自动等于参数化 CAD 或可直接打印的封闭实体。

## 路线 2：NeRF 神经辐射场

**原理：学习空间中的密度以及随观察方向变化的颜色，通过体渲染合成照片。**

原始 NeRF 使用多层感知机，把三维位置和观察方向映射为密度与 RGB。可以写成 `F(x, y, z, direction) → density, color`。

渲染时，每个像素对应一条相机射线；沿射线采样很多空间点，查询密度和颜色，按透射率与遮挡累积为像素颜色。训练把渲染结果与真实照片比较，更新场景函数参数。[NeRF 项目与论文](https://www.matthewtancik.com/nerf)

典型用途是新视角合成。原始方法的网络查询与采样成本较高；后续方法使用哈希网格、稀疏结构、小网络等加速，所以不能笼统地说所有 NeRF 都很慢。NeRF 的密度不等于可靠的表面距离；可以通过额外方法提取点云或网格，但网格质量取决于方法和约束。[Nerfstudio](https://github.com/nerfstudio-project/nerfstudio)

## 路线 3：3DGS 三维高斯泼溅

**原理：以大量可移动、可拉伸、带颜色与不透明度的三维高斯拟合场景。**

每个高斯类似边缘渐隐的椭球，包含位置、尺度、旋转、不透明度与球谐颜色参数。训练在渲染与图像比较中更新这些参数，并按策略调整高斯数量。查看时，将高斯投影为屏幕上的椭圆色斑，排序后透明混合成图像。

它的速度优势来自显式表示和 GPU 友好的光栅化，减少了原始 NeRF 式的沿射线反复查询。原论文在其测试条件下报告 1080p、至少 30 FPS 的实时渲染；不代表所有设备、场景或训练过程都达到同样速度。[3DGS 原论文](https://arxiv.org/html/2308.04079v1)

三维高斯确实具有空间位置与形状，但它不天然形成连通物体表面。好看的鞋子高斯不一定具有可靠鞋底、正确内部结构或已知厘米尺度。反射外观的拟合也不等于恢复可物理重光照的材质。阅读 [完整实现](implementation.md)。

## 路线 4：神经隐式表面重建

**原理：学习一个明确描述表面的函数，而不仅是自由分布的密度。**

以符号距离场 SDF 为例，函数给出每个位置距物体表面的距离以及内外符号；`f(x)=0` 的位置集合就是表面。NeuS、VolSDF 等方法把表面函数与可微体渲染连接，用照片误差和几何约束优化，最终提取网格。[NeuS](https://lingjie0206.github.io/papers/NeuS/)、[VolSDF](https://lioryariv.github.io/volsdf/)

目标是兼顾图像监督与更合理的几何表面，适合研究高质量网格。但透明、反光、薄结构与少视角仍有挑战，不应宣传为任何材料都能准确扫描。KIRI 对外称其 Featureless Object Scan 使用 NSR；这不能证明其内部直接采用上述任何一个开源实现。

## 路线 5：预训练几何预测

**原理：先从大量数据学习几何关系，使用时从照片直接预测点图、深度、相机等。**

DUSt3R 从图像对预测点图，再通过全局对齐建立共同空间；VGGT 使用 Transformer 从一个、少量或多个视角预测相机内外参数、深度、点图和点轨迹。可以再做几何优化，预测结果并非测量真值。[DUSt3R](https://github.com/naver/dust3r)、[VGGT](https://github.com/facebookresearch/vggt)

这一类主要改变空间估计方式，不限定最终表示。VGGT 官方提供 COLMAP 格式导出及可选 BA，结果能供 NeRF／高斯训练使用：`照片 → VGGT → 相机与空间点 → 3DGS → 高斯查看器`。

“一次前向预测”与“每个场景长时间优化”是不同计算安排，但混合流程可以同时使用两者。速度、尺度、跨场景可靠性都需按数据核验。

## 路线 6：生成式三维

**原理：利用当前参考与预训练先验，生成完整的三维资产表示。**

单张鞋子正面照片没有完整鞋底信息。生成模型可以根据学到的规律补出合理背面，但这部分是推断，不能说恢复了原物体的真实细节。

常见方式包括：生成一致的多视角图像后重建；用二维扩散模型的指导信号优化三维表示；直接用扩散／流模型生成三维潜在表示，再解码。TRELLIS 的公开实现使用结构化潜在表示和流模型，能够解码为网格、高斯或辐射场。[TRELLIS](https://github.com/microsoft/TRELLIS)

所以“最后是高斯文件”不证明过程一定是传统多视角 3DGS 优化；“最后是网格”也不证明使用了摄影测量。Meshy、Tripo 是生成产品，闭源架构不能仅凭结果推断。我们之前研究的 threestudio 也是组织生成指导与三维优化的框架，区别于只做实拍静态场景拟合。

## 六类方法如何选择与组合

| 目标 | 优先研究 | 需要额外确认 |
| --- | --- | --- |
| 真实外观、网页自由观看 | 3DGS | 拍摄覆盖、显存、压缩、查看器兼容 |
| 几何资产、表面编辑、测量 | 摄影测量或神经表面 | 实际尺度、独立误差、拓扑、薄结构 |
| 辐射场和新视角算法研究 | NeRF、3DGS | 留出视角质量与相同硬件性能 |
| 少图快速得到空间初值 | DUSt3R、VGGT | 泛化、尺度、几何一致性与后续优化 |
| 单图／文字创作对象 | 生成式三维 | 不可见部分的推断、纹理、后续编辑 |
| 既要逼真显示又要碰撞 | 高斯＋网格混合 | 两种表示的对齐与独立质量 |

以上是基于技术结构的选型判断，不是六种方案在同一数据集上的实测排名。

## 邻近技术与常见误解

- **LiDAR／RGB-D** 是额外的距离观测来源；可以通过定位、配准与深度融合辅助几何或高斯重建，不是 3DGS 的另一个名称。
- **SLAM** 侧重持续定位与建图；它产生的相机信息或地图可以供后续重建使用。
- **360° 全景** 常把二维画面映射到球面，可以转头观看；只有全景并不等于能在空间中平移并得到正确视差。
- **多图不等于多视角重建**：参考图拼贴、不同物体批量生成、同一物体的几何重建是不同任务。
- **神经网络不一定都是生成大模型**：场景 NeRF、预训练几何网络、图像生成模型承担不同职责。
- **能旋转不等于精确重建**：手工建模和程序搭建也能形成真实可旋转的几何。
