## 为什么研究

- 原库能力：集中收集公开案例，提供公司目录、主题与年份元数据，以及直达原文的链接；浏览与检索这些线索即可缩小阅读范围。
- 解决的问题：减少寻找工程实践资料的时间，为具体技术问题提供原始案例入口。
- 值得学习的内容：文章中的设计约束、方案取舍、迁移过程和效果验证。
- 本次目标：明确能力边界，确定中文研究卡片、跨项目关联与最小实验的扩展方向。

## 当前结论

研究版本包含 343 个文章条目，按 39 个公司／品牌分组，提供标题、链接、主题和年份。它收集工程实践文章，既包括过去问题的解决案例，也包括架构演进和新技术应用；“经典”是阅读评价，不能视为逐篇已经验证的属性。

上游主要提供索引，不包含逐篇深度案例分析，也没有可运行的业务系统、全文检索、自动抓取或智能问答功能。复杂技术位于链接指向的文章中。

对本研究仓库的价值，是为开源项目提供工程背景和实验选题。建议沿着“文章案例 → 问题与约束 → 关联项目 → 最小实验 → 结果与适用边界”开展研究。细节见[研究笔记](notes.md)。
