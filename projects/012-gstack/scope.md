# gstack：技能范围与能力摘要

gstack 是面向软件研发的 Agent 技能与配套工具库。它把需求探索、产品与工程规划、设计实现、代码审查、排障、测试、交付和复盘等专业方法写成技能，由宿主 Agent 结合项目上下文、模型判断与可用工具执行，形成方案、代码修改、测试证据、发布记录和可复用经验。

研究固定于上游 `71f6048e8ada25180e61438abc1d98cb151fe9a7`，package 版本 1.84.1。按独立定义统计共 **57 项、12 类**：54 个一级目录技能、总路由、贡献者适配技能、浏览器提取示例各 1 项。平台生成副本和测试夹具不重复计数；这个数字不是每个宿主都默认安装的命令数量。

## 单个 skill 如何产生能力

输入任务、代码、URL、日志或前序产物 → 读取技能规定的事实来源与专业步骤 → 模型分析并作取舍 → 调用终端、文件、浏览器及可用服务 → 检查实际结果 → 修正或交接产物。

`SKILL.md` 负责组织方法，模板与宿主配置处理适配；浏览器运行时、hook 和证据脚本负责部分可确定的操作与检查。自然语言步骤由模型解释执行，可靠性取决于模型、上下文、工具和验收覆盖。技能不会通过安装就训练出一个新模型，角色名也不代表一定运行了多名独立 Agent。

## 使用场景与对我们的意义

适合新功能立项、已有项目改造、上线前检查、故障排查、网页信息提取、开发者工具改进、长任务续接和团队经验沉淀。小任务可以只选一个技能，复杂任务可按产物衔接多个技能。

对研究总仓库，可复用“资料 → 方案 → 最小实现 → 验证 → 结论”的工作方式，将编号、原库去重、来源、许可证、截图与部署规则写进检查清单。扩展方向包括领域技能、团队工具连接、证据与版本关联、成功流程固化和真实任务评测。减少返工、提高效率属于待测量收益，不能由技能数量推断。

## 本地网页提供什么，实际验证到哪里

本地新增中文能力图、57 项逐技能原理解读、九阶段收录检查器实践、五组可编辑教学输入及真实测试证据。网页浏览与规则校验在前端运行；不在线调用模型、安装技能、操控用户浏览器账户或执行生产发布。

实际案例的 21 项规则测试和 17 项浏览器检查通过，审查发现并修复 1 项 URL 边界缺陷，保留 20/21 → 21/21 的回归证据。7 项技能采用方法适配，`ship` 仅采用本地交付检查；上游原生浏览器、全量 hook、跨模型、iOS、GBrain 和上游完整发布流程未复现。本研究网页的 GitHub Pages 部署另外记录，不据此把 `/ship` 改记为完整原生执行。

安全报告不等于安全认证；浏览器 QA 不覆盖全部业务；本地性能采样不代表线上用户；保护 hook 不等于完整系统沙箱。产物与证据应按每个技能的实际覆盖范围解释。
