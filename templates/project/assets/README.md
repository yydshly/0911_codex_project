# 项目配图

本目录存放该项目的真实截图和示意图。

- 其他图片使用语义化名称，例如 `settings-panel.png`、`architecture.svg`。
- 每张图配一句说明，标明所展示的功能；引用上游图片时记录来源。
- 建议封面使用约 16:9 比例，并压缩体积，保证 GitHub 页面加载顺畅。
